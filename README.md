# مغامرة الحروف الإنجليزية

لعبة تعليمية عربية لممارسة كتابة الحروف الإنجليزية والاستماع إلى الكلمات والقصص.

## النشر عبر GitHub Pages

هذا مجلد موقع ثابت؛ `index.html` هو الصفحة الرئيسية، والوسائط المطلوبة موجودة في `audio/` و`images/`.
بعد رفع الملفات إلى مستودع GitHub عام، فعّل Pages من إعدادات المستودع باختيار **GitHub Actions** كمصدر للنشر.
